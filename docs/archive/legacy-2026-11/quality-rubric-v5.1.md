# Rubbish 质量评分细则 v5.1

> 版本 5.1 · 2026-11 · 本文件是审稿人、编辑和外部 AI 评分工具的唯一判分依据。
> 代码常量：`apps/backend/app/domain/quality/rubric.py` → `RUBRIC_VERSION = "5.1"`。
> 改口径必须升版本并整库重评；不同版本的分数不可比。

## 一、两条赛道

先判文体，再判赛道：

- **学术论文**：有摘要、关键词、正文、章节结构，围绕一个可回答的问题展开；用 `paper` 轨道。
- **荒诞论文**：保留论文外壳，但核心设定、推演或语气是反讽、悖论、夸张的；仍用 `paper` 轨道。
- **副刊/随笔/小说/评述/公告**：不以论文格式回答研究问题；用 `essay` 轨道，不套论文五维。

`paper` 下再分 `serious` / `absurd`。分类存疑时先留 `absurd`，登记到
`docs/content-taxonomy-review.md`，不要为了“看起来正经”硬升 serious。

## 二、学术赛道：五维百分制

每个维度 0–100 分，按权重折算后相加。**每个维度必须给分；理由与证据选填。**

| 维度 | 权重 | 它问什么 |
|---|---:|---|
| 选题与真问题 `question` | 20 | 问题是否真实、具体、未被回答；增量相对哪篇文献 |
| 论证与自洽 `argument` | 25 | 前提→结论有无跳跃、循环、未交代假定；反面解释是否处理 |
| 方法与可复现 `method` | 20 | 数据、样本、参数、失败案例是否交代到别人能照着做 |
| 证据与结论 `evidence` | 20 | 证据强度是否匹配结论强度；相关是否被写成因果 |
| 规范与诚信 `integrity` | 15 | 引用可核、数据可追、声明完整；造假 0 分一票否决 |

## 三、荒诞赛道：六维百分制

每个维度 0–100 分，按权重折算后相加。**每个维度必须给分；理由与证据选填。**

| 维度 | 权重 | 它问什么 |
|---|---:|---|
| 荒诞度 `absurdity` | 20 | 反讽、悖论、夸张推演、冷面错位是否进入正文并持续起作用 |
| 荒诞设定与原创 `concept` | 20 | 设定是否真荒诞、新鲜、有记忆点，而不是普通吐槽换皮 |
| 内部自洽 `coherence` | 15 | 在这个设定下规则是否自洽、前后不打架 |
| 一本正经的执行 `execution` | 20 | 是否用完整结构把荒诞当正事推进，而不是段子拼贴 |
| 材料与梗的可核查 `material` | 15 | 梗、数据、案例有出处，或自造规则被明确交代 |
| 文风与节奏 `voice` | 10 | 读起来有节奏、有包袱、不啰嗦，荒诞感靠写法立住 |

### 荒诞度怎么给分

荒诞度不是“离谱程度”，而是**荒诞信号是否真的承担论证/叙事功能**：

- 90+：至少 3 处可指认的荒诞信号（反讽、归谬、悖论、夸张推演、冷面错位、疑问式反问），且每一处都推进论点或人物；删掉任何一处，文章会塌。
- 70–89：荒诞信号清楚，但有一两处只负责搞笑，删掉不影响主线。
- 50–69：有荒诞姿态，主要靠标题、开头或结尾玩梗；正文仍像普通说明文。
- <50：几乎没有荒诞设计，或荒诞只停留在骂人/堆梗/无意义反转。

**硬门槛**：荒诞度 < 50 → 总分封顶 69；自洽 < 50 → 封顶 59；执行 < 50 → 封顶 69；
任一维度 < 60 → 封顶 79；两项及以上 < 50 → 封顶 49。

## 四、学术赛道硬门槛

- 诚信 0 分 → 总分归零（一票否决）。
- 任一维度 < 50 → 总分封顶 59；两项及以上 < 50 → 封顶 49。
- 任一维度 < 60 → 总分封顶 79。
- 论证 < 50 → 封顶 59。

## 五、分区

| 总分 | 等级 |
|---:|---|
| 90–100 | T1（顶刊级；95+ 为 T1+ 范本） |
| 80–89 | Q1 一区 |
| 70–79 | Q2 二区 |
| 60–69 | Q3 三区 |
| 50–59 | Q4 四区 |
| 0–49 | R 退稿 |

## 六、评分流程（必须遵守）

1. **先审内容，后打分。** 分类、文体、结构、参考文献未修完，不进入评分。
2. 每篇必须逐篇读正文；禁止只按标题/格式批处理。
3. 理由与证据选填；填了就写具体位置（章节/段落/图号/表号/引用编号/公开链接），不写“整体不错”。
4. 参考文献必须真实可核；不得用“某某”“佚名”或伪造机构凑数。查不到就不写，并在 `integrity` 扣分。
5. 全部文章修完后统一重评；不得边修边出分，也不得用旧分覆盖新稿。
6. 评分结果写回 `resources.quality_score / quality_grade / quality_breakdown / reviewed_at`；
   `review_reports` 只作为历史审计记录，不直接当对外分数。

## 七、与旧版的关系

- v3.0 的七维、v4.0 的旧权重均已废弃。
- 对外统一称“五维两段式”只适用于学术赛道；荒诞赛道是六维，不硬凑五维。
- 任何页面、文档、AI 提示词若写“七维”或“证据必填”，以本文件与 `RUBRIC_VERSION` 为准。
