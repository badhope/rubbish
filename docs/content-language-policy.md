# 内容语言规范（2026-11-17）

适用于本刊全部 274 篇 canonical 内容与前端 UI 文案。目标是“中文稿全中文、英文稿全英文、双语信息分开写”，避免中英混排。

## 1. 中文稿

1. **标题**：数据库 `resources.title`、Markdown 一级标题、页面标题均使用中文主标题。英文原题不得放在中文标题行内。
2. **正文**：以中文写作。不得出现整句英文、英文段落或“英文原句 + 中文翻译”的逐句混排。
3. **允许保留的英文**：
   - 专有名词、产品名、机构名、人名、文献原题；
   - 学科通用缩写与术语（如 DNA、RNA、PCR、DOI、CLC、CRediT、LLM、API）；
   - 公式、代码、变量名、基因序列、文件格式；
   - 引文中的外语原句，但必须紧跟中文释义，且仅作为材料引用，不得成为正文叙述语言。
4. **双语信息分离**：
   - 英文标题统一放在文末 `## 英文标题（独立存档）`；
   - 英文摘要统一放在文末 `## 英文摘要（独立存档）`；
   - 中英对照表必须分列，不得在同一单元格内中英混写；
   - 正文中的英文原句若必须保留，移到文末独立存档，正文只留中文。
5. **结构标题**：`摘要`、`关键词`、`引言`、`方法`、`结果`、`讨论`、`结论`、`致谢`、`参考文献` 等一律中文；不得使用 `Abstract`、`Introduction`、`Methodology`、`Results`、`Discussion`、`Conclusion`、`Keywords`、`Acknowledge` 作为中文稿标题。

## 2. 英文稿

1. 标题、摘要、正文、图表标题、致谢、参考文献均使用英文。
2. 不得在英文正文中夹入中文段落；中文元数据（如中文标题、中文摘要）如确需保留，单独放入 `## 中文标题（独立存档）` / `## 中文摘要（独立存档）`。

## 3. 前端 UI

1. 面向用户的按钮、标签、提示、弹窗标题使用中文。
2. 技术标识（PDF、Word、Markdown、DOI、CLC、CRediT、API、ID、Token 等）可作为术语保留；能用中文表达时优先中文（如“令牌”“资源 ID”）。
3. 不得出现“接收（Accept）”“小修（Minor Revision）”这类中英并列标签；中文界面只写中文。

## 4. 验收清单

- [ ] 中文稿首行一级标题为中文，且与 `resources.title` 一致；
- [ ] 中文稿正文无整句英文、无英文段落；
- [ ] 英文标题/摘要均在文末独立存档；
- [ ] 中英对照表分列；
- [ ] 结构标题全部中文；
- [ ] 前端构建产物中无中英并列 UI 标签；
- [ ] 修改后 274 篇 canonical 与生产 `md5` 全量一致。
