## How Papers Are Organized

Papers are grouped by year, then by field:

```
papers/economics-management/
├── 2020/
│   ├── finance/
│   ├── marketing/
│   └── ...
├── 2021/
└── ...
└── 2026/
```

Each field folder contains subfolders for the 6-level taxonomy (Field → Topic → Journal Tier → Method → Scenario → Paper). See the [EM taxonomy config](https://github.com/badhope/ScholarLib/blob/main/.scholarlib.yaml) for the full hierarchy.
