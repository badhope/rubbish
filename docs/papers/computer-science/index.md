## How Papers Are Organized

Each topic contains its own subfolder under `papers/computer-science/`. Inside a topic folder you will typically find:

- Year-based subfolders (e.g. `2020/`, `2021/`, …)
- One or more `.md` files per paper with metadata
- `.pdf` files for the full paper
- A `README.md` for that topic

Browse via the sidebar on the left, or use the search bar at the top.
