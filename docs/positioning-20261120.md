# Rubbish 定位与用词（2026-11-20）

## 一句话

**Rubbish 是一个荒诞科研社区：把不正经的问题当正经课题做，把过程、失败和结果拿出来讨论。**

英文描述统一为 **Absurd Research Community**。不再使用 Academic Writing Forum、Journal、Paper 等旧口径。

## 五个一级入口

`首页 / 社区 / 档案 / 指南 / 我的`

- **社区**：短帖、提问、研究计划、实验记录、失败复盘、组队与站务。
- **档案**：值得长期读的研究记录与自由创作，按“实证研究 / 荒诞研究 / 创作”分区。
- **指南**：怎么提问、怎么记录、怎么标注虚构、怎么处理版权与隐私。
- **我的**：收藏、积分、通知、设置；不再暴露投稿、审稿、等级申请。

## 社区板块

`研究计划 / 实验记录 / 田野观察 / 失败档案 / 研究讨论 / 科研生存 / 组队招募 / 站务 / 公告`

## 公开文案禁用词

以下词不再出现在用户可见页面、SEO、README、营销页：

论文、论文体、期刊、投稿、审稿、审稿人、录用、发表、卷期、副刊、DOI、ISSN、CN、主编、编辑部、学术出版、底刊。

内部代码、历史数据和后台旧接口可以保留字段名，但不在前台展示。

## 文案原则

1. 从论坛/社区起点写，不写“从期刊转过来”“不是期刊”“不做出版”这种转型或防御叙事。
2. 先讲能做什么：提问、立题、记录、失败、复盘、拆台、组队。
3. 荒诞是研究对象，不是营销形容词；方法、材料、过程要能说清。
4. 虚构标注、真实材料可核查、真人隐私、版权四条边界保留。
5. 中文与英文分开写，不在中文句子里混排英文品牌词之外的内容。

## 视觉原则

- 一屏只放一个部分，其余下滑。
- 社区首页首屏只放品牌、定位、两个动作。
- 列表只在“需要连续浏览”的地方使用；入口页优先用索引行、分区、不对称版面。
- 桌面与手机分别设计，不把桌面版缩放成手机版。
