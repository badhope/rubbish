# 自动化规则配置指南

> 适用：Rubbish 主题论坛确定性审核链路  
> 更新：2026-11-24

## 一、规则分层

### 硬规则

命中即拒绝，不进入人工队列，不提供“通过”入口：

- 广告引流：联系方式与交易话术组合、站外拉群、代写代考等。
- 辱骂攻击：直接人身攻击、歧视性辱骂。
- 站规词：站内明确禁止的词表。

硬规则由 `app/core/moderation.py` 中的 `rejection_detail()` 执行。误判只能修改代码并重新发布，不走后台权重。

### 软规则

只加分，不直接拒绝；分数达到人工阈值进入 `manual_review`：

| 信号 | 默认权重 | 触发条件 | 典型误判 |
|---|---:|---|---|
| 疑似联系方式 | 32 | 邮箱、手机号、QQ/微信等联系方式 | 引用公开论文通讯作者 |
| 站外链接 | 14；每多一条 +4 | http/https 链接 | 引用公开资料、作品原文 |
| 信息量偏低 | 22 | 正文过短、重复字符、几乎无信息 | 一句话提问、公告式短帖 |
| 格式异常 | 10 | 全大写、连续感叹号、异常符号密度 | 标题党、引用原文 |

### 自动归类

未选分区时，按标题与正文关键词匹配到保守分区；匹配不到落入默认分区。自动归类只影响展示位置，不替代人工判断内容是否切题。

## 二、默认配置

| 配置 | 默认值 | 边界 |
|---|---:|---|
| 自动发布 | 开启 | 关闭后所有新主题帖进入人工核验 |
| 人工阈值 | 40 | 1–99；越低越严格 |
| 预计时限 | 30 分钟 | 1–1440 分钟 |
| 联系方式权重 | 32 | 0–100 |
| 站外链接权重 | 14 | 0–100 |
| 信息量偏低权重 | 22 | 0–100 |
| 格式异常权重 | 10 | 0–100 |

风险分是软规则加权求和，硬规则不进入分数。阈值调整后只影响新提交和作者重新提交，不回溯已公开内容。

## 三、场景预设

### 平峰期（默认）

- 自动发布：开
- 阈值：40
- 权重：32 / 14 / 22 / 10
- 目标：正常内容直接公开，明显边界进入人工。

### 活动期 / 风险期

- 自动发布：关
- 阈值：30
- 权重：40 / 20 / 25 / 12
- 所有新主题帖人工过一遍；活动结束后恢复默认。

### 技术分享期

- 自动发布：开
- 阈值：50
- 站外链接权重：8
- 目标：减少 GitHub、文档、论文链接的误判；联系方式仍保持高权重。

### 冷启动期

- 自动发布：开
- 阈值：35
- 信息量偏低权重：16
- 目标：鼓励短提问，但仍拦截空内容与纯表情。

## 四、怎么改

1. 进入 `/admin/content?section=moderation`。
2. 右上角“规则设置”；只有主编或管理员可见并可保存。
3. 修改开关、阈值、时限、权重。
4. 保存后新提交立即生效；已进入队列的条目保留原风险分与时限。
5. 在“处理记录”观察一批新内容，确认误判率可接受。

### 回滚

- 规则误判集中：先把对应权重调回默认，必要时关闭自动发布。
- 代码级硬规则误判：回滚 `app/core/moderation.py` 到上一版本并重启服务。
- 数据库级配置误改：重新保存默认值，不直接改表。

## 五、规则覆盖矩阵

| 场景 | 期望结果 | 覆盖方式 |
|---|---|---|
| 正常长文主题帖 | 自动公开 | 软规则低分 |
| 含邮箱的合作帖 | 人工核验 | 联系方式 32 分 |
| 含多个站外链接 | 人工核验 | 链接 14 + 4/条 |
| 一句话空帖 | 人工核验 | 信息量偏低 22 |
| 全大写标题党 | 人工核验 | 格式异常 10 |
| 广告引流 | 直接拒绝 | 硬规则 |
| 辱骂攻击 | 直接拒绝 | 硬规则 |
| 关闭自动发布 | 全部人工 | 配置开关 |
| 作者改正文 | 重新人工 | 编辑重审 |
| 批量处置 | 全部落审计与通知 | 批量接口 |
| 非运营访问队列 | 403 | 权限校验 |
| 非主编改规则 | 403 | 规则权限 |

## 六、测试与验收

```bash
cd apps/backend
.venv/bin/pytest tests/test_forum.py tests/test_forum_moderation.py -q
```

压力回归用于证明状态不漂移、批量接口不丢项；它不是生产并发压测，生产并发与锁竞争需在部署后用独立 QA 数据继续验证。

- 正常主题自动公开。
- 联系方式主题进入人工队列。
- 通过后公开、拒绝后隐藏。
- 非运营访问 403。
- 关闭自动发布后全部人工。
- 统计、审计事件、批量处置、作者通知。
- 规则设置返回有效默认权重。
- 50 条边界主题批量入队、批量通过、审计与通知连续落库；`tests/test_forum_moderation_stress.py` 单次创建 50 条约 0.5 秒，完整回归约 2 秒。

新增规则时必须同时补：

1. 命中用例。
2. 不命中用例。
3. 阈值边界用例。
4. 人工处置后的状态流转用例。

## 七、无大模型能力边界

这套规则只处理文本表层特征，不处理反讽、隐喻、图片、音视频、跨帖团伙行为、事实核查、版权与隐私细节。规则的目标是减少人工阅读面，不是给出最终判决。遇到以下情况直接转人工：

- 内容表面正常但语境可疑。
- 同一账号短时间重复发相似内容。
- 涉及真人隐私、纠纷、法律风险。
- 图片或附件是主要信息载体。
- 作者对处置结果提出申诉。
