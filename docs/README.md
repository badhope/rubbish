## Writing a document

- Write for someone who is about to do the task, not for a release announcement.
- Keep one topic per file. If a document needs a table of contents, it probably needs splitting.
- Put commands in copyable blocks and name the directory they run from.
- Do not restate the same architecture in three files. Link instead.
