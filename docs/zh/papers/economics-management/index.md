## 论文组织方式

论文按年份分组，再按领域细分：

```
papers/economics-management/
├── 2020/
│   ├── finance/
│   ├── marketing/
│   └── ...
├── 2021/
└── ...
└── 2026/
```

每个领域目录包含六级分类的子目录（领域 → 主题 → 期刊级别 → 方法 → 场景 → 论文）。完整层级结构请参见 [EM 分类配置](https://github.com/badhope/ScholarLib/blob/main/.scholarlib.yaml)。
