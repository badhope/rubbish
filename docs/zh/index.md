## 快速统计

- **33** 个计算机科学主题
- **18** 个经济与管理领域
- **7** 个出版年份覆盖（2020 – 2026）
- **2498+** 篇论文条目（仅 CS，持续增长中）

## 如何使用

1. 在侧边栏选择一个板块（计算机科学或经济与管理）。
2. 按主题或年份浏览。
3. 每篇论文都有 `.bib` 文件 —— 复制到你的 LaTeX 项目即可。
4. 需要全文 PDF？每篇论文页面都有下载链接。

> **注意**：此仓库是 [`ScholarLib-CS`](https://github.com/badhope/ScholarLib-CS) 和 [`ScholarLib-EM`](https://github.com/badhope/ScholarLib-EM) 的合并产物。所有内容已迁移至此。
