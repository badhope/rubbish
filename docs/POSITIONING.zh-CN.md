# 产品与用词

**[English](POSITIONING.md) · 简体中文**

## 一句话

**Rubbish 是一个公开写作与讨论社区：把问题写开，把过程留下，把话说明白。**

英文统一使用 **Rubbish — Public Writing & Discussion**。

## 一级入口

`首页 / 内容 / 合集 / 讨论 / 怎么用 / 我的`

- **首页**：一句话、几篇值得先读的作品，以及正在发生的讨论。
- **内容**：研究长文和荒诞写作放在一起读；可以按话题、年份或分区筛选。
- **合集**：按一个题目把内容串成一条阅读线，只表示阅读顺序，不排名。
- **讨论**：写法、复盘、组队，还有写作之外的生活；短话留在这里。
- **怎么用**：第一次来先走一遍，知道东西放哪、话在哪说。
- **我的**：作品、收藏、通知、经验与设置。

## 身份

`读者 / 作者 / 互评成员 / 内容整理 / 站务组`

- **读者**：注册即可阅读、收藏、评论和参与讨论。
- **作者**：发布第一篇作品后获得。
- **互评成员**：作者申请，站务组通过；能给互评中的作品写意见。
- **内容整理**：处理合集、认领和站内说明。
- **站务组**：处理举报、公告、成员与站点运行。

## 用词

- 用**作品**、**发布**、**公开**、**互评**、**基础检查**、**处理意见**、**通过 / 不通过**。
- 用**合集**表示一组阅读顺序，不用卷、期、刊号。
- 用**分区**表示讨论区里的分类，不用版块。
- 用**话题**表示作品的方向，不用研究方向、学科。
- 用**经验**表示成员活跃度，不用活跃值、XP、积分等级。
- 公开只表示内容能被读到；这里不做学术评价，也不出具任何机构证明。

## 文案原则

1. 从具体的东西写起：一篇稿、一句卡点、一次翻车、一个还没想清的问题。
2. 先讲能做什么，不用“我们不是什么”来定义自己。
3. 短句，少形容词；能写“晚上十点，光标还在闪”，就不写“致力于打造优质创作生态”。
4. 可以认真，也可以荒诞；虚构、夸张和整活要在正文里说清楚。
5. 保留四条边界：真实材料能对上，虚构明确标注，真人隐私不写，转载注明来处。

## 视觉原则

- 一屏只讲一件事，其余往下排。
- 首页先给一句话和两个动作，不堆统计卡。
- 列表只用在需要连续浏览的地方；入口页优先用索引行和不对称分区。
- 桌面与手机分别设计，不把桌面版缩小成手机版。
