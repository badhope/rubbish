# 产品与用词

**[English](POSITIONING.md) · 简体中文**

## 一句话

**Rubbish 是一个荒诞科研社区：把不正经的问题当正经课题做，把过程、失败和结果拿出来讨论。**

英文统一使用 **Absurd Research Community**。

## 五个一级入口

`首页 / 社区 / 档案 / 指南 / 我的`

- **社区**：写作讨论、记录与复盘、组队招募、创作生活、站务与反馈。
- **档案**：值得长期读的研究记录与自由创作，按“实证研究 / 荒诞研究 / 创作”分区。
- **指南**：怎么提问、怎么记录、怎么标注虚构、怎么处理版权与隐私。
- **我的**：收藏、积分、通知与设置。
- **首页**：品牌、定位句和两个动作。

## 版块

`写作讨论 / 记录与复盘 / 组队招募 / 创作生活 / 站务与反馈`

对外称号统一为 `成员 / 评审 / 编辑 / 主编`；内部角色码与权限不变。

## 文案原则

1. 从社区本身写起，不解释“以前是什么”，也不用“不是什么”来定义自己。
2. 先讲能做什么：提问、立题、记录、失败、复盘、拆台、组队。
3. 荒诞是研究对象，不是营销形容词；方法、材料、过程仍要能说清。
4. 虚构标注、真实材料可核查、真人隐私、版权四条边界始终保留。
5. 中文与英文分开写，不在同一个句子里混排，专有名词除外。

## 视觉原则

- 一屏只放一个部分，其余内容往下排。
- 社区首页首屏只放品牌、定位句和两个动作。
- 列表只在“需要连续浏览”的地方使用；入口页优先用索引行和不对称分区。
- 桌面与手机分别设计，不把桌面版缩放成手机版。
