## 📌 如何使用

1. **点击上方年份链接**，进入对应年份目录
2. 每篇论文以 `作者-年份-标题简写.pdf` 命名，方便识别
3. 直接点击 PDF 文件即可下载或在线预览
4. 论文文件名格式：`FirstAuthor-YYYY-ShortTitle.pdf`

## 🤝 贡献论文

欢迎提交 PR 补充该领域的经典论文！请遵循以下命名规范：

```
FirstAuthor-YYYY-ShortTitle.pdf
```

例如：`Vaswani-2017-AttentionIsAllYouNeed.pdf`
