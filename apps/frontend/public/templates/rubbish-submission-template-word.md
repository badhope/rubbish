# Rubbish 作品排版说明（Word 版）

> 版本 3.1 · 2026-11 · 对应《Rubbish 写作与发布规范》
>
> **用法**：在 Word 里先设好「标题 1 / 标题 2 / 正文 / 图表题注」四个样式，之后全篇套用。不要逐段手调字号——手调出来的层级，转成 PDF 常会乱，站内识别也读不准。

## 〇、字体

不必套用任何一套固定排版的官方字体。下列字库均为 OFL 或等效自由许可，可用于排版、PDF 嵌入与公开分发：

| 用途 | 字体 | 许可 |
| --- | --- | --- |
| 正文、开头、图表题注、出处条目 | **思源宋体 / Noto Serif SC** | OFL 1.1 |
| 标题、开头与话题标签 | **思源黑体 / Noto Sans SC** | OFL 1.1 |
| 署名、书名号与中文引号 | **霞鹜文楷 / LXGW WenKai** | OFL 1.1 |
| 西文与数字 | **DejaVu Serif** | DejaVu Fonts License |
| 行内代码、公式编号 | **DejaVu Sans Mono** | DejaVu Fonts License |

本机没有安装时，Word 会回退到系统衬线字体；不影响阅读与互评，但导出 PDF 前建议安装，免得嵌进去的是另一套字。

## 一、页面与基础样式

| 项目 | 建议 |
| --- | --- |
| 纸张 | A4（210 × 297 mm） |
| 页边距 | 上下 2.54 cm，左右 3.17 cm（Word「普通」） |
| 正文中文字体 | 思源宋体 / Noto Serif SC |
| 正文西文字体 | DejaVu Serif |
| 正文字号 | 10.5 pt（五号） |
| 行距 | 1.5 倍（或固定值 22 pt） |
| 段前段后 | 0 |
| 首行缩进 | 2 字符（用「段落 → 特殊格式 → 首行缩进」，不要敲空格） |
| 对齐 | 两端对齐 |

**不要做**：不要用空格做缩进，不要用回车换页，不要手动敲编号。用 Word 的「多级列表」，或直接写「1 问题」让样式层级生效。

## 二、标题层级

| 层级 | 样式名 | 字体 | 字号 | 加粗 | 段前/段后 |
| --- | --- | --- | --- | --- | --- |
| 题名 | 标题 | 思源黑体 | 18 pt | 是 | 6 / 10 pt |
| 一级节 | 标题 1 | 思源黑体 | 14 pt | 是 | 14 / 6 pt |
| 二级节 | 标题 2 | 思源黑体 | 12 pt | 是 | 10 / 4 pt |
| 三级节 | 标题 3 | 思源黑体 | 10.5 pt | 是 | 8 / 3 pt |

一级节写「1 问题」即可。这里没有“章”，也不必把节名写成“引言 / 方法 / 结果 / 讨论 / 结论”的研究套子；自由创作可以直接用「一 / 二 / 三」或小标题。

## 三、开头与话题

- 「开头」二字用**思源黑体五号（10.5 pt）**，与正文同段开头，后面直接接内容。
- 开头两三百字，写清问题、做法、发现与边界。自由创作可只写梗概。
- 「话题：」用**思源黑体五号**，后接四到六个词，用分号「；」分隔。

## 四、图表

### 图

- 图**居中**，宽度不超过正文宽度。
- 图题在图**下方**，格式：`图 1　图题`（图号与图题之间用全角空格），思源宋体 9 pt、居中、不加粗。
- 图内不要嵌文字标题——标题由图题提供。
- 图注只写一行短标题（≤140 字，句末不加句号）。正文分析不要写成孤立的单句，免得被误排成小号图注。
- 分辨率 ≥ 300 dpi；位图宽度 ≥ 1000 px。不要整页截图。

### 表

- 用**三线表**：顶线（1.5 pt）、表头线（1 pt）、底线（1.5 pt），不要竖线。
- 表题在表**上方**，格式：`表 1　表题`，思源宋体 9 pt、居中。
- 单位写在表头内，如「耗时（ms）」，不在单元格里重复。
- 表内文字小五（9 pt），数字右对齐或小数点对齐。

## 五、公式

- 用 Word 自带公式编辑器，不要用图片代替公式。
- 独立公式居中，编号右对齐，格式 `(1)`、`(2)`。
- 行内变量用斜体，单位用正体。

## 六、引用与出处

- 格式统一即可，建议顺序编码制。
- 正文引用写 `[1]`、`[1,2]`、`[1-3]`；文末同序排列。
- 「引用与出处」用**标题 1**样式，条目用小五（9 pt）、悬挂缩进 2 字符。

示例：

```
[1] 作者. 题名. 出处 / 站点 / 书目信息, 年. 链接，或 ISBN、DOI（如有）.
[2] 作者. 书名. 版本. 出版地: 出版社, 年. ISBN.
[3] 作者. 题名. 见：编者. 书名. 出版地: 出版社, 年: 页码.
```

## 七、材料与边界说明

1. **虚构与真人**：如为虚构、讽刺或思想实验，写明“虚构创作”；确认未指向可识别个人的隐私与名誉。
2. **AI 辅助**：写明工具与用途；未使用可写“无”。
3. **数据与代码**：已公开（给链接或 DOI）/ 可索取（向谁要、多久回应）/ 受限（说明原因）。
4. **利益冲突**：有就写清，没有写“无”。

## 八、公开范围与许可

- **公开范围**：公开（站内与访客可读）/ 仅站内登录可读 / 受限（说明谁能看到）。
- **使用许可**：你保留著作权；本站用于展示、索引与备份。转载、翻译、改编请注明来源。
- **转载与引用**：他人作品的图片、文字、数据，已注明来源与许可；未获授权的部分不在此列。

## 九、发布前自检

- [ ] 题名与开头能独立读懂
- [ ] 每一节只回答一个问题
- [ ] 图表都有编号与标题，正文有引用
- [ ] 引用与出处真实可查，正文与文末对得上
- [ ] 虚构与真人边界已交代
- [ ] 公开范围与许可已写明
- [ ] 全篇套用样式，没有空格缩进、没有手动编号
- [ ] 导出 PDF 检查：标题层级、图表位置、公式是否错位

## 十、导出与上传

- 建议同时保留 **.docx 源文件**与 **PDF**：PDF 便于互评阅读，源文件便于修改与重排。
- 文件名：`作者姓-年份-短题名.docx`，例如 `张-2026-面条与发酵.docx`。
- 高清原图可另附 PNG/TIFF（300 dpi），在正文注明「另附原图 图1.png」。
