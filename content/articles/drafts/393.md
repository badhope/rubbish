

#  1 引言

在近年来的中文互联网文化热议中，演员张志坚塑造的两个经典荧幕形象构成了极具戏剧张力的跨时空对照：在《大明王朝1566》中，他饰演的“小阁老”严世蕃身处权谋与风月场却始终人间清醒，一眼便能看穿一切温情脉脉背后的利益算计[1]；而在《人民的名义》中，他饰演的法学教授兼高级官员高育良，却在面对经过突击培训、专门研读《万历十五年》以迎合其喜好的高小凤时彻底沦陷，并极其诚恳地向外界辩护——“她不一样”[2]。

这一流行文化热点折射出一个颇具社会学意味的悖论：为何拥有同一副面孔、同等权谋智商甚至同样与“大明”深度绑定的两个精英角色，在面对标准化的情感套路时，一个清醒如刀，另一个却深陷幻觉？更耐人寻味的是，高育良那句饱含深情的“她不一样”，与当代互联网上广泛流传的“舔狗”语录（如“她回我‘嗯’是因为太累了”“她只收我红包说明把我当自己人”）在叙事逻辑上呈现出惊人的同构性。

既有网络讨论多将“舔狗”心理简单归结为年轻群体的卑微或缺乏社会阅历，却忽视了这种“情感例外论”在精英阶层中的普遍存在。基于此，本文以严世蕃为清醒对照，将高育良的经典独白与当代“舔狗”语录置于同一话语分析框架下，旨在回答两个核心问题：

（1）高育良与当代普通情感投入者是如何通过话语加工，将显而易见的常规套路与冷漠反馈建构为“独一无二的深情”的？


（2）“她不一样”这句宣言在个体的日常面子维护与身份认同中，究竟扮演了何种角色？

# 2 研究方法

##  2.1 研究路径与理论视角

本研究采用**跨文本比较研究**与**话语分析（Discourse Analysis）**相结合的质性研究路径。在理论工具上，主要借用戈夫曼（Erving Goffman）的“拟剧论”与“面子工程（Face-work）”视角[4]，以及布尔迪厄（Pierre Bourdieu）的“文化区隔”概念[5]，剖析个体如何利用文化符号与修辞策略来粉饰不对等的情感交换。

## 2.2 语料来源与筛选标准

为保证分析的代表性与可复现性，本研究选取三类公开文本作为核心语料：

**（1）清醒对照语料（严世蕃文本）**：取自《大明王朝1566》中严世蕃涉及权色、利益与人际博弈的经典台词[1]，用于界定“去魅状态”下的现实主义话语特征。

**（2）精英幻觉语料（高育良文本）**：取自《人民的名义》中高育良评价高小凤及为这段关系辩护的核心段落[2]，重点考察其如何调用《万历十五年》等文化符号[3]。

**（3）大众幻觉语料（当代“舔狗”语录）**：采自社交媒体平台广泛流传、引发高频共鸣的日常聊天记录与自我安慰语录。筛选标准为“呈现明显的单向付出与自我合理化特征”；排除标准为“纯商业营销号编造的极端段子”及“带有明确商业带货意图的剧本”。

# 3 结果与讨论

## 3.1 体面的代价：严世蕃的“去魅”与高育良的“自我赋魅”

跨文本对比显示，严世蕃与高育良之所以在面对情感陷阱时走向截然相反的结局，关键不在于智力高低，而在于**对“体面人设”的依赖程度**。

在《大明王朝1566》的语境中，严世蕃从不掩饰自己的欲望与功利立场。由于不需要在道德和审美上维持“高洁”的前台表演[4]，他能够坦然直面一切关系的交易本质——别人投其所好，他心知肚明“所图不小”，绝不会产生“对方爱上了我的灵魂”的错觉。

反观高育良，其长期经营的“学者型官员”身份构成了一套沉重的体面枷锁。如果承认自己与高小凤之间只是俗套的“权色交易”，其苦心维持的精英自我认同将瞬间崩塌。因此，高育良迫切需要对这段关系进行**“去商品化”的自我赋魅**。当高小凤仅仅通过短期突击背诵《万历十五年》[3]这一极低成本的文化表演时，高育良便如获至宝地将其升华为“文化区隔”的证明[5]——她不是俗气的风月女子，她是“懂明史、不世俗”的精神知音。**这说明**：越是看重精神体面与精英身份的个体，在陷入低级套路时，往往越需要借助宏大或高雅的文化符号来完成自我欺骗。

## 3.2 话语的同构性：大众“舔狗”语录的三重修辞建构

如果剥离掉“明史”“法学教授”等精英修辞外壳，高育良的话语体系与当代互联网“舔狗”语录在底层逻辑上完全一致。通过对高频流传的大众“舔狗”语录进行话语归类，可以清晰识别出三种最具共鸣的自我说服机制。

### 3.2.1 微弱反馈的“符号学过载”：标点、字数与轮回的等待

在高频出现的“舔狗”语录中，最典型的一类是对极低成本社交信号的过度阐释，例如：**•** *“她今天回复了我‘嗯嗯’，比昨天的‘嗯’多了一个字，说明她对我的态度软化了。”*

**•** *“她回我消息总是隔好几个小时，不像那些整天抱着手机的俗人，她有自己的独立生活，这正是她特别的地方。”*

**•** *“她把我拉黑了，一定是怕自己控制不住想找我聊天，怕耽误我工作和前程。”*

在日常社交规范中，单字敷衍、长时间冷处理乃至主动切断联系，均属于明确的排斥信号。然而在“情感例外论”的滤镜下，投入者通过极端的**符号学过载**，将“冷漠”重编码为“克制”，将“敷衍”重编码为“惜字如金”。这与高育良仅凭几句《万历十五年》的读书心得便推导出“灵魂伴侣”的逻辑如出一辙——两者均通过大幅拉低正向证据的门槛，硬生生在荒漠中虚构出了绿洲。

### 3.2.2 工具化待遇的“纯爱化重编码”：情绪垃圾桶与红包叙事

面对不对等的资源索取与单向情绪劳动，大众“舔狗”语录发展出了一套极具悲剧美感的**“特权叙事”**，将自己被当作工具人的处境升华为不可替代的情感地位：**•** *“她平时不理我，但一难过、一和别人吵架就找我倾诉——别人只配分享她的快乐，只有我能承接她的脆弱。”*

**•** *“她收了我的转账却不说话，不是贪财，是因为她把我当自己人，跟我不用客气，怕说谢谢显得生分。”*

**•** *“昨晚三点她让我去买热粥，虽然最后她和别人去吃夜宵了，但她饿的时候第一个想到的是我，我在她心里终究是不一样的。”*

这种话语策略的核心在于**去商品化与道德升华**。如同高育良将高小凤对权力与资源的依附解读为“她只是需要一个避风港”，大众语录也将显而易见的单向索取重新定义为“深度信任的证明”。通过把“被利用”翻译成“被需要”，投入者成功在心理上把屈辱感转化为了使命感。

### 3.2.3 道德区隔与“救赎者幻想”：庸俗的他人与懂她的我

正如高育良通过“明史”将自己与俗气的权色交易者切割开来，“舔狗”语录中同样高频出现**“道德区隔”**话语，通过贬损外部竞争者来确立自身的唯一性[5]：**•** *“她身边那些人都是图她的外表和新鲜感，根本不懂她深夜发朋友圈时的孤独，只有我是真心心疼她。”*

**•** *“她总说我们不合适，其实是因为她以前受过情伤，不敢轻易交出真心；只要我再多坚持一下，一定能融化她。”*

此类语录构建了“世俗浅薄的旁人 vs. 深情专一的我”的二元对立，不仅彻底豁免了对方反复拒绝或暧昧推诿的责任，还顺理成章地赋予了投入者一种“精神救赎者”的高尚角色。
为直观呈现三类文本在话语建构上的跨阶层同构，表 1 对其在典型情感场景中的归因路径进行了对比总结。


表 1　三类文本在典型情感交互场景中的话语建构对比**
| | | | | |
| --- | --- | --- | --- | --- |
| **现实交互场景** | **严世蕃话语（清醒对照）** | **高育良话语（精英建构）** | **“舔狗”语录（大众建构）** | **核心话语策略** |
| 精准迎合或微弱回应 | “做足了功课，所图不小” | “她不一样，她真懂明史” | “她回我‘嗯嗯’多了一个字，她心里有我” | 微弱符号的过度赋魅 |
| 长期冷淡 / 很少主动 | “欲擒故纵，抬高价码” | “她单纯、不世俗、不粘人” | “她回消息慢是因为独立，不像俗人总看手机” | 冷漠信号的纯爱重编码 |

**表 1 结果说明**：学历、阅历与社会地位的提升，并不能帮助个体免疫“情感例外论”，而仅仅是升级了**自我说服的修辞精美度**。大众用朴素的“她只是太忙了”完成心理闭环，高育良用高雅的“万历十五年”完成同样的闭环，二者在社会心理机制上并无本质高下。

### 3.3 “她不一样”的真正主语：脆弱的自我认同辩护

为什么无论是位高权重的高育良，还是屏幕前反复咀嚼“嗯嗯”二字的当代网友，在面对旁观者反复劝告时，依然顽固地捍卫“她不一样”这一命题？从戈夫曼的“面子维护”理论来看[4]，这实际上是一场关于**自我尊严的保卫战**。

在非对称的情感投入中，承认“她和别人一样（只是在走常规套路，或者单纯不喜欢我）”，会立即引发剧烈的身份危机：

**（1）**对高育良而言，承认高小凤是标准化的“美人计”，等于承认自己这位精明一世的封疆大吏，竟然为了一个俗套的局搭上了毕生清誉；

**（2）**对大众语境下的“舔狗”而言，承认对方只是在消遣自己，等于承认自己长达数月的情绪劳动、熬夜守候与物质付出，沦为了一场毫无尊严的独角戏。

**这说明**：“她不一样”表面上是在赞美“她”，实际上真正的主语是“我”。只有拼命论证“她是世间独一无二的例外”，局中人才能体面地向自己和世界宣告：“我不是一个被低级套路蒙蔽的蠢货，我只是在进行一场世俗之人无法理解的高级深情。”

# 4 结论

（1）严世蕃与高育良的跨文本对照表明，“情感例外论”的产生并非源于智商或阅历不足，而是源于个体对“体面人设”与情感正当性的刚性需求。

（2）高育良的“明史知音论”与当代互联网“舔狗”语录在话语结构上高度同构，均通过微弱符号的过度阐释、单向付出的纯爱化重编码及道德区隔，将不对等的交换关系包装为纯粹的灵魂契合，差异仅在于修辞包装的阶层品味。

（3）“她不一样”的底层潜台词实为“我不一样”。人们之所以在不对等的关系里反复自我说服，往往并非出于愚蠢，而是因为难以承受真心错付后的体面坍塌。然而，真正走出这一幻觉的关键，并不在于执着地搜集更多证明对方虚伪的证据，也不必为了追求“严世蕃式的清醒”而从此走向彻底的冷酷与功利，而在于试着卸下那副沉重的体面枷锁，温和地允许自己承认：我也不过是一个会被普通套路打动、渴望被认真回应、也会偶尔看走眼的普通人。承认“她其实并没有那么不一样”，并不会否定你曾经付出过的真诚——那些熬过的夜、递出的善意与笨拙的深情，证明的是你本身拥有爱人的能力，而非对方有多么不可替代。当你不再需要靠证明“她有多特别”来挽救自己的尊严，能够坦然接纳现实的边界、把本就属于自己的温柔收回并转身离开时，真正的清醒与体面，才算刚刚开始。
