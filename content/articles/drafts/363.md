<a id="摘要"></a>
## 摘要
人体排便感知与排便输出属于两套相对独立、神经调控耦合的生理系统。临床及人群亚健康状态中普遍存在 **便意频繁、急迫，但实际粪便排出量显著不足** 的失衡表型，归属于 [功能性直肠高敏感](https://pubmed.ncbi.nlm.nih.gov/31279241/) 及亚临床 [里急后重](https://www.uptodate.com/contents/tenesmus-clinical-manifestations-and-etiology) 谱系。现有研究多聚焦于便秘、肠易激综合征宏观症状归纳，对 **便意异常信号的发生机理、离子通道传导变异、肠壁机械‑神经转换机制、假性排便反射通路激活** 等微观生物机制阐释不足。

本文基于 [肠道神经生理学](https://doi.org/10.1038/nrgastro.2019.134)、平滑肌生物力学、内脏感觉传导通路及盆底反射弧调控机制，系统拆解 **生理性正常便意传导通路** 与 **病理性变异异常传导通路** 的差异，阐明：便意本质为直肠壁机械感受器的电位信号传导结果，与结肠粪便容积无绝对正相关；排便量由结肠内容物体积、水盐代谢、移行复合运动决定。直肠感受器阈值下调、黏膜微炎症致敏、盆底肌本体感觉紊乱、肠神经系统兴奋性异常，会诱发 **无容积支撑的假性便意信号**，最终造成感知与输出的完全解离。本文深度解析信号变异传导链条，为肠道功能性感知障碍提供微观机理依据。

<a id="一引言"></a>
## 一、引言
正常人体排便生理依赖 **结肠动力系统、直肠感知系统、盆底肌调控系统、中枢整合系统** 四级协同调控。在标准生理状态下，结肠经消化残渣蓄积、水分重吸收、塑形推送，使定量粪便扩张直肠肠壁，激活机械感受器，经盆神经、腹下神经传入脊髓骶段及大脑皮层，产生匹配容积强度的便意感知，继而触发协调的盆底肌舒张、直肠收缩、腹压辅助，完成等量排便输出。

但在现代人群慢性疲劳、久坐制动、饮食低纤维、自主神经紊乱的背景下，出现典型的 **感知‑容积脱耦联** 病理状态：直肠可在几乎无足量粪便容积扩张的条件下，持续发放高强度传入电位，中枢持续解码为强烈便意；而结肠内容物蓄积量不足，无法提供有效排便输出，形成高频便意、低量排泄的特征性病征。

既往医学研究多从宏观症状学定义该现象为里急后重、功能性肛门直肠痛、直肠高敏感综合征，但 **并未系统阐释信号为何会在无物理容积刺激下自主激活、传导、放大**。本文从微观生物机理出发，分层解析正常传导通路、异常变异传导通路、致敏放大机制及肌肉协同失调机理，构建“感受器致敏—离子通道异常—外周神经超传导—中枢感知误判—输出失配”的完整机制模型。

## 二、正常生理状态下：便意产生与排便输出的标准生物机制

<a id="21-粪便蓄积与排便量的生成机理"></a>
### 2.1 粪便蓄积与排便量的生成机理
排便量的生理学决定主体为 **近端结肠与横结肠** 的水盐代谢及 [移行复合运动（MMC）](https://doi.org/10.1111/j.1365-2982.2011.01725.x)。

食物残渣经小肠吸收后进入结肠，结肠上皮细胞通过 **钠‑氯协同转运蛋白、水通道蛋白 AQP3/AQP4** 进行主动重吸收，将液态残渣塑形为固态粪便。粪便总容积取决于：膳食纤维持水胶体含量、结肠传输时长、肠道菌群发酵产物体积、每日摄入底物总量。

结肠具备 **容积储备特性**：只有当残渣累积突破直肠阈值容积（成人 $20$–$40\ \mathrm{ml}$ 扩张量），才可触发初级排便反射。因此，**排便量是纯粹的容积力学结果，属于外周实体输出**，不依赖神经感知。

<a id="22-生理性便意的完整神经传导通路"></a>
### 2.2 生理性便意的完整神经传导通路
便意不属于容积检测，属于 **机械形变的电信号感知**。直肠肠壁存在多层感知结构，构成标准传导链：

1. **效应感受器层**：直肠黏膜下层、环肌层、纵肌层分布 Meissner 触觉小体、Pacinian 环层小体、肠壁牵张感受器。正常生理下，仅肠壁被粪便 **持续性、均匀性扩张形变** 时，感受器包膜受压形变。
2. **机械‑电转换机制**：形变牵拉激活感受器细胞膜 [机械门控离子通道（Piezo1/Piezo2）](https://www.nature.com/articles/nature14532)，阳离子内流，产生局部感受器电位。
3. **外周神经传入**：电位达到阈电位后，通过 **骶丛盆神经（S2–S4）** 传入脊髓骶段后角，完成一级信号中继。
4. **脊髓‑中枢整合**：脊髓向上投射至脑干孤束核、丘脑内脏感觉核，最终投射至大脑皮层岛叶、扣带回，中枢解码产生 **真实、匹配容积强度的便意感知**。
5. **传出应答通路**：中枢下达指令，抑制盆底肌、肛门内括约肌张力，直肠平滑肌节律收缩，匹配容积完成排便。

**正常核心逻辑**：容积扩张 → 机械形变 → 可控离子内流 → 标准电位传导 → 中枢精准感知 → 等量输出。

<a id="三病理核心便意与便量失衡的变异生物传导机制"></a>
## 三、病理核心：便意与便量失衡的变异生物传导机制

该症状的本质，是 **肠道感受器‑离子通道‑外周神经‑脊髓中继‑中枢解码** 全链条发生 **致敏性变异**，形成一套 **无粪便容积、无物理扩张、自主持续发放的异常信号通路**，也是本文重点创新机理阐释。

<a id="31-感受器层面阈值下调与超敏致敏始发机制"></a>
### 3.1 感受器层面：阈值下调与超敏致敏（始发机制）
长期久坐、肛周充血、黏膜微水肿、轻度炎症刺激，不会产生大量粪便，但会改变感受器特性：
1. 直肠黏膜微循环淤血，组织间隙渗透压升高，细胞轻微肿胀，使 **感受器处于预牵拉状态**；
2. 微炎症释放组胺、前列腺素、缓激肽，**降低 Piezo2 机械门控通道激活阈值**；
3. 正常需要 $30\ \mathrm{ml}$ 以上扩张才可激活的电位，**$5\ \mathrm{ml}$ 微量残渣、黏液、气体摩擦即可触发通道开放**。

此阶段完成了 **生理性阈值 → 病理性超敏阈值** 的变异：**极小刺激 = 极大电位输出**。

<a id="32-离子通道传导变异信号放大瀑布效应核心微观机理"></a>
### 3.2 离子通道传导变异：信号放大瀑布效应（核心微观机理）
正常感受器为“线性传导”，变异后形成 **正反馈放大传导**：
1. Piezo 通道异常频繁开放，持续钠离子内流，使传入神经纤维 **静息电位绝对值降低**，处于去极化预备状态；
2. 神经纤维兴奋性上调，不应期大幅缩短，**信号发放频率成倍提升**；
3. 继发电压门控钙通道异常开放，钙离子内流激活神经末梢递质释放增加；
4. 谷氨酸、P 物质大量释放，对外周神经形成 **致敏性瀑布放大**。

**关键结论**：此时的便意信号 **不是粪便产生的，而是离子通道异常放电持续产生的虚假传导信号**。

<a id="33-外周神经传导变异异位放电与持续传入"></a>
### 3.3 外周神经传导变异：异位放电与持续传入
正常神经仅在刺激时产生动作电位，致敏后出现 **异位自发性放电**：

盆神经末梢因长期炎性致敏、淤血缺氧，细胞膜稳定性下降，**在无任何外界机械刺激时，自主产生节律性动作电位**，持续上传至脊髓。

大脑接收到持续高频电信号，会 **强制误判为直肠持续充盈、粪便堆积**，形成持续性坠胀便意、排不尽感，但结肠本身无任何新增粪便容积。

<a id="34-脊髓中枢层面突触可塑性改变与感知固化"></a>
### 3.4 脊髓中枢层面：突触可塑性改变与感知固化
长期异常信号传入，会导致 **脊髓后角突触可塑性重构**：
1. 内脏感觉突触传递效率长期上调，形成 [中枢敏化](https://doi.org/10.1038/nrgastro.2020.124)；
2. 大脑皮层对直肠信号的分辨能力下降，无法区分“真实粪便扩张信号”和“炎症异常放电信号”；
3. 形成 **感知固化记忆**，即使局部刺激消失，中枢仍会持续性生成便意感知。

这解释了：为何很多人排空粪便后，**便意依然强烈、无法缓解**。

<a id="35-盆底肌反射弧失调假性便意的二次放大机制"></a>
### 3.5 盆底肌反射弧失调：假性便意的二次放大机制
盆底肌与肛门括约肌存在闭环反射弧：
1. 正常排便：直肠收缩 → 括约肌舒张，协同输出；
2. 病理状态：盆底肌长期紧张痉挛、肛提肌张力过高，导致 **括约肌舒张不全、出口阻力升高**。

少量粪便排出后，肠壁压力无法完全释放，残留微小形变持续刺激感受器；同时 **盆底肌本体感觉神经紊乱**，将肌肉紧张张力信号错误解码为直肠充盈信号，**二次放大假性便意**，形成恶性循环。

<a id="四便意‑便量失衡的分型生物机制解析"></a>
## 四、便意‑便量失衡的分型生物机制解析

<a id="41-容积不足型真性少便假性便意"></a>
### 4.1 容积不足型（真性少便、假性便意）
机制：饮食纤维匮乏 → 结肠持水不足、残渣蓄积不足 → **排便量生理基数极低**
叠加：直肠感受器致敏 → 微小摩擦刺激持续放电 → 高频便意
最终：**无物可排、持续有便意**

<a id="42-动力紊乱型肠移行复合运动异常"></a>
### 4.2 动力紊乱型（肠移行复合运动异常）
结肠 MMC 节律紊乱，推送能力下降，粪便分段滞留于上段结肠，无法整体下移；仅有少量末端残渣抵达直肠，持续刺激敏感感受器，造成 **信号满负荷、容积空缺** 的脱耦联状态。

<a id="43-炎症致敏型器质性微损伤传导变异"></a>
### 4.3 炎症致敏型（器质性微损伤传导变异）
直肠炎、痔核充血、黏膜糜烂导致局部炎症介质浸润，直接改变离子通道特性，属于 **病理性持续异常放电源**，是顽固性频繁便意、少量排便的器质性机理。

<a id="五该失衡表型的持续性恶性循环生物模型"></a>
## 五、该失衡表型的持续性恶性循环生物模型
1. 初始诱因：久坐、低纤维、焦虑、轻微炎症
2. 微观变异：Piezo 通道阈值下调、神经兴奋性升高
3. 信号异常：无容积自主放电，假性便意频发
4. 行为代偿：频繁如厕、久蹲用力
5. 结构加重：肛周淤血、黏膜水肿、盆底肌痉挛加剧
6. 中枢固化：脊髓敏化、皮层感知错乱
7. 稳态失衡：永久形成“便意多、排便少”的病理稳态

<a id="六结论"></a>
## 六、结论
**便意感知与粪便排出量属于两套调控完全独立、仅生理耦合的生物系统**。排便量由结肠底物容积、水盐代谢、肠道动力决定，属于客观容积输出；便意由直肠机械感受器、离子通道、盆神经传导、中枢解码决定，属于主观电信号感知。

人群中高发的便意频繁但排便量稀少的核心病理，并非便秘残渣堆积，而是 **肠道感觉传导通路的全方位病理性变异**：包括感受器阈值下调、机械门控通道异常开放、神经异位放电、脊髓中枢敏化、盆底反射弧失调。其本质是 **神经系统致敏后的虚假信号传导**，实现了“无物理容积支撑的持续性便意输入”，与低位的粪便容积输出形成不可逆脱耦联。

本研究厘清了既往症状学认知的局限，从微观生物传导层面解释了感知‑容积失衡的核心机理，为功能性肛门直肠感知障碍的干预、修复、临床诊疗提供了精细化的生物学理论支撑。
