# Rubbish 文章正文

本目录保存当前服务器上的文章正文与作者姓名，跟随开源主仓一起公开。这里只放观众本来就能看到的文章数据，不放密码、账号、token、服务器密钥或审读评分材料。

## 数量

| 目录 | 内容 | 数量 |
|---|---|---:|
| `published/` | 已发布文章正文，按资源 ID 命名 | 274 |
| `drafts/` | 在审、修回、待处理稿，按投稿 ID 命名 | 21 |
| `duplicate-records/` | 同一资源的重复录用记录，只有元数据，没有独立正文 | 15 |
| `manifest.json` | 310 条记录的标题、作者、状态、路径、SHA256 | 310 |
| `INDEX.md` | 人读索引 | 310 |

## 字段边界

- 作者只使用生产库 `resources.authors` / `submissions.authors` 中的公开姓名数组。
- 不使用 `authors_meta` 中的邮箱、用户 ID、认领状态等字段。
- 文章正文按服务器上的 Markdown 原样保存，不做评分、不改写、不补引用。
- `drafts/` 是未处理内容，后续再逐篇处理；不要把它当成已审稿。
- `duplicate-records/` 不是另一篇文章，正文在同资源 `published/` 文件里。
