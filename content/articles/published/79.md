# 学术期刊影响因子的数域拓展

## 摘要

期刊影响因子（IF）通常定义为“前两年论文在报告年的被引次数除以这两年的论文数”，取值一般是非负有理数。本文用一个玩具模型讨论：如果把“引用”从当前窗口扩展到负时间、间接引用和跨领域影响，IF 的数域能否从非负有理数扩展到实数甚至复数。文章把负年份引用写成带符号的加权项，把间接引用写成 0 到 1 之间的折减系数 S，把跨领域影响写成虚部 S'，得到 IF = S + iS' 的复平面解释。必须说明：这不是期刊评价方案，也没有任何真实 IF 数据；它是一场关于“指标能否被无限拓展”的数学讽刺。拓展出来的负数、无理数和虚数，不能直接用于排名，更不能替代同行评审。

## 关键词

影响因子；数域拓展；间接引用；复平面；科学计量；讽刺模型

## 1 引言

影响因子是期刊评价里最常被引用的数字之一。它的标准算法不复杂：某期刊 2025 年的 IF，等于 2023—2024 年发表的论文在 2025 年被引总次数，除以这两年的论文总数。分母不为零时，结果通常是一个非负有理数；分母为零，期刊已经停刊，不再计算。

这个定义的问题也很明显：它只看两年窗口，只算直接引用，只在一个学科内部比较。于是，有人用五年 IF、特征因子、H 指数来补；也有人干脆把 IF 当宣传口号。本文不打算提出一个更科学的指标，而是反过来问一个略带恶作剧的问题：如果沿着数域扩展的历史，把 IF 从非负有理数一路扩展到复数，会发生什么？

文章的方法不是实证，而是“公理化玩具”：先规定几条看起来合理的性质，再构造一个满足这些性质的函数，最后讨论它的解释。它的价值不在于给出新指标，而在于暴露“把复杂影响压成一个数”的荒诞。

## 2 模型

### 2.1 时间维度：负年份引用

以某刊 2025 年 IF 为例，把 2023—2024 年的两年窗口压缩成时间轴原点，以一年为单位 1。t=1 表示 2025 年末，t=-1 表示 2023 年末。若一篇 2023—2024 年发表的论文，在 2021 年就被引用，那么这次引用落在负时间。

把这部分写成带符号的加权和：

IF_time = [C(0→1) * (+1) + C(0→-1) * (-1) + ... + C(0→-n) * (-n)] / N0

其中 C(0→k) 是 0 年论文在 k 年被引次数，N0 是 0 年论文总数。正向引用增加 IF，负向引用减少 IF；IF 因此可以取负值。文章把“越负”解释为“越前瞻”：论文还没发表就被引用，说明概念提前影响了别人。这个解释是修辞，不是事实；负引用在现实数据里几乎不存在，真实引用也不可能发生在论文发表之前。

### 2.2 间接引用：折减系数 S

直接引用之外，还有间接引用：B 引用了 A 的观点，C 又引用了 B，却没有回溯 A。若把 C 算作对 A 的一次完整引用，会高估 A；若完全不算，又会低估 A。合理的做法是给间接引用一个 0 到 1 之间的折减系数。

文章要求 S 满足五条性质：随代数和次数增加；后一代的边际贡献递减；0<S<1；代数或次数趋于无穷时 S 趋于 1；每一代用同一递推规则。一个满足这些性质的构造是几何级数：

S = 1 - exp(-lambda * m)

其中 m 是间接引用的“代际深度”，lambda 是折减强度。m 越大，S 越接近 1；lambda 越大，折减越快。这个式子不是唯一解，文章只用它做演示。

若 A 被 B1…Bn 直接引用，每个 Bi 又各自带来间接引用，则 A 的总引用可写为：

C_total = n + sum_i S_i

S_i 取 0 到 1 之间，所以 C_total 可以是非整数、无理数。IF 的分子因此不再局限于整数比，IF 可以取全体实数。

### 2.3 空间维度：跨领域影响

IF 还忽略了一个维度：影响发生在哪个领域。一篇研究中餐的论文被理论物理论文引用，说明它突破了本领域；一篇只被同领域引用，说明它更专注。文章把跨领域影响记为 S'：

S' = (B 的领域数 - A 与 B 重合的领域数) / A 的领域数

若 B 覆盖的领域比重合部分多，S'>0，表示影响更广；若 B 更窄，S'<0，表示影响更专。把 S 和 S' 组合，得到复形式的玩具 IF：

IF = S + i * S'，其中 i^2 = -1

实部 S 表示时间维度的引用折减，虚部 S' 表示空间维度的跨领域影响。图 2 是这个复平面的解释：实部向右为“号召性”，向左为“前瞻性”；虚部向上为“广泛性”，向下为“专业性”。

这个复平面不是标准数学意义上的复分析，也没有可计算的真实数据。它只是一个比喻：把一个本来只能排大小的一维指标，硬拉成二维，让“广而浅”和“窄而深”可以被同时说出口。

### 2.4 数域拓展的代价

从非负有理数扩展到实数、复数，看起来只是“多了几个维度”，实际上丢掉的是“可排序性”。复数没有自然的大小顺序，两个复数不能直接说谁“更高”；一旦 IF 变成复数，期刊排名、分区、考核都无法直接使用。更麻烦的是，负年份引用和虚部没有可核对的经验对应物：它们可以被公式定义，却不能被数据证伪。数学上自洽，不等于计量上有意义。

## 3 讨论

这套拓展在形式上自洽，但在评价上几乎不可用。第一，负年份引用在现实中不存在，真实引用只能发生在发表之后；把它写成“前瞻性”，是把不可能的数据当成美德。第二，间接引用的折减系数没有实证依据，lambda 取多少完全取决于作者；换一个 lambda，排名就会变。第三，跨领域影响需要领域分类，而领域边界本身是人为的；把中餐和理论物理放在同一个复平面，只会制造新的任意性。第四，复数 IF 不能排序，也不能和传统 IF 直接比较；它只能被解释，不能被使用。

文章因此把它定位为“数学讽刺”，而不是“指标创新”。它想说明的是：当人们要求一个指标同时承载时间、空间、间接影响和跨领域影响时，指标会变得越来越复杂，最后失去可解释性。一个不能解释的数，比一个不完美的数更危险。

### 3.1 一个可检验的替代

与其把 IF 扩展到复数，不如做可检验的分解：把引用拆成“直接/间接”“正向/负向”“同领域/跨领域”，分别报告计数与比例；用引用语境分析判断“支持/批评/仅提及”；再用五年窗口与领域归一化做敏感性分析。这些分解仍然是数字，但每个数字都能被数据核对。讽刺模型的价值，是提醒我们不要用一个数解释一切；真正的研究，应该把“一个数”拆成“可验证的多个数”。

## 4 研究局限

第一，没有真实 IF 数据，全部为形式推演。第二，负年份引用是反事实设定，不对应任何可观测事件。第三，S 的几何构造不是唯一解，也没有做敏感性分析。第四，领域分类没有操作化定义，S' 无法从现实数据计算。第五，复数 IF 没有排序规则，不能用于期刊比较。第六，文章不构成对现行 IF 的替代方案。

## 5 结论

把 IF 从非负有理数扩展到复数，在形式上可以做得很漂亮：负时间给出“前瞻性”，间接引用给出无理折减，跨领域影响给出虚部。但这个扩展也把指标推到了不可解释、不可比较、不可验证的边界。文章的真正结论不是“复数 IF 更好”，而是“不要指望一个数同时解释所有影响”。影响因子可以继续用，但它需要和同行评审、领域差异、引用语境一起看；把它拓展成复数，只是把这个问题放大给人看。

## 补记：影响因子的数域拓展是讽刺

把负年份引用写成带符号加权项，把间接引用写成 0 到 1 的折减系数 S，把跨领域影响写成虚部 S'，得到 IF = S + iS'。这个复平面解释很漂亮，但它不是期刊评价方案，也没有真实 IF 数据。负数、无理数、虚数不能直接用于排名，更不能替代同行评议。

指标拓展的诱惑，在于“更全面”听起来总是对的：加负时间，能算历史影响；加间接引用，能算间接贡献；加跨领域，能算社会影响。但每加一层，权重从哪来、数据怎么取、误差怎么传，都会变成新的黑箱。黑箱越多，指标越像占卜。

文章是一场数学讽刺，价值在提醒：不要用“维度更多”掩盖“定义更模糊”。影响因子已经够复杂，再拓展数域，不会让它更科学，只会让它更难反驳。真正该拓展的，是同行评议的质量，不是指标的虚部。

## 补记：指标拓展要先问“权重从哪来”

负年份引用、间接引用、跨领域影响，每加一层，都要问权重从哪来。负时间的衰减系数、间接引用的折减系数 S、跨领域的虚部 S'，如果没有经验依据，就只是把主观判断写成参数。参数越多，指标越像可调的叙事。

复平面解释很漂亮，但漂亮不等于可用。负数不能排名，虚数不能比较；把 IF 写成 S + iS'，更像一个数学玩笑，而不是评价方案。真正的问题不是“数域够不够大”，而是“指标是否在测量它声称测量的东西”。

文章是一场讽刺，价值在提醒：不要用“维度更多”掩盖“定义更模糊”。影响因子已经够复杂，再拓展数域，不会让它更科学，只会让它更难反驳。要改期刊评价，先改同行评议与开放获取，不是改虚部。
