# 站务文本归档（notices）

本目录存放从文章库下架的站务、编辑部口径文本。它们不是研究作品，作者为编辑部口径，因此不再以文章身份对外，也不进入 `content/articles/` 的作品清单、索引与推荐池。

## 这批文件是什么

- 11 篇 Markdown，资源 ID 305–315，原位于 `content/articles/published/`，2026-11-23 归档到本目录。
- 类型包括站点公告、合集启动说明、更正/撤稿/署名变更政策、编辑方针、栏目征稿、读者互动与技术现场等。
- 正文按服务器上的 Markdown 原样保存，未做改写、评分或补引用；文件名保持 `<资源ID>.md` 不变。

## 去向与留档

- 这些文本对应的对外口径，由站点后台的 **announcements 表（公告机制）** 承载；线上是否露出、以何种公告形式发布，由生产库的公告流程处理，本仓库镜像不连接数据库。
- 逐篇的资源 ID、投稿 ID、标题、作者、原路径、新路径、SHA256、原状态、下架原因与目标载体，见同目录 `mapping.json`，可回溯核对。
- 归档前后文件字节数与 SHA256 一致；本目录是完整副本，未做物理删除。

## 边界

- 本目录内容不参与文章计数，不计入 `articles/manifest.json` 的作品记录。
- 若后续公告内容需要修订，改动发生在公告载体上；本归档只保留下架时点的原始文本，不随公告更新而改写。
